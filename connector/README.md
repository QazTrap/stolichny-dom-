# STOLDOM Connector — протокол обмена v1

Статус: реализован экспорт браузера. Тестовый внешний Connector v0.3.0 проверен пользователем для записи банковских комиссий без проведения; другие виды массового импорта требуют проверки.

JSON UTF-8, format=STOLDOM-1C, schemaVersion=1. Экспортируются все операции по текущему фильтру (включая строки за пределами видимых 400); неполные реквизиты и возможные дубли маркируются. Деньги — строки целых чисел в сотых долях единицы валюты (amountScale=2); делить на 100 точно, проверять итоги. Неизвестную валюту, организацию или счёт нельзя подставлять автоматически. Дата — строка источника, требуется строгое преобразование на стороне 1С. БИН/ИИН, КНП, счета и номера документов — строки.

В accounting передаются предложенные тип и вид документа, Дт/Кт, статья ДДС. contract=null: договор следует выбирать по справочнику конкретной базы, не создавать автоматически. Бухгалтер должен подтвердить выбор организации, расчётного счёта, валюты, контрагента, договора (когда нужен), вида операции, счетов и статьи ДДС. Не импортировать строки с ошибками до их исправления. Импортёр обязан сверять суммы, проверять дубли по устойчивым банковским идентификаторам и реквизитам; при неоднозначности требовать ручного решения. Номер строки не является уникальным идентификатором операции. Создавать только непроведённые документы; не менять существующие документы. Проверить итоговые суммы и показать журнал результатов. Версии конфигурации и имена метаданных определить по тестовой базе Бухгалтерия для Казахстана 3.0. Сборка и испытания .epf требуют Конфигуратора 1С. Облачный провайдер должен разрешить внешние обработки.
